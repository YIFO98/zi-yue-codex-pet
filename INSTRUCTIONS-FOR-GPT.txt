Install and verify the Yue Li R4 pet only when the user requests installation.

1. Extract the entire package and read docs/INSTALL.md.
2. Detect the operating system and the existing CODEX_HOME setting.
3. On macOS, run /bin/bash ./install-yue-li-macos.sh and then /bin/bash ./verify-yue-li-macos.sh.
4. On Windows, run powershell -NoProfile -File .\install-yue-li-windows.ps1 and then powershell -NoProfile -File .\verify-yue-li-windows.ps1.
5. If a system policy blocks execution, use the documented manual installation instead of weakening that policy.
6. Report the destination, both payload SHA256 values and the actual verification result. Do not claim UI acceptance from file verification.
7. Ask the user to reopen their client and select Yue Li / 月璃 if needed. Preserve any existing Zi Yue installation.

Do not edit the artwork, use administrator privileges, alter account Pets, or skip verification.
