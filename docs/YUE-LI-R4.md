# 月璃 R4 · 2026-10-15

本次同步的是已确认的御剑版月璃，包含九组标准动作与十六个视线方向。

专注工作和检查成果原本都坐在电脑前，区别过小。R4 仅重做 `review` 行：双手捧蓝莲，侧头端详并眨眼点头；专注工作继续使用耳机、木桌和紫色笔记本。其余十行与确认过的 R3 图集逐像素相同。

## 素材验证

- 透明 v2 图集：1536 × 2288，73 个有效帧，15 个空白格。
- 本地图集结构、背景残留、边缘和动作质量检查通过。
- Pets 服务端预检通过，保存后回读像素一致。
- WebP 无损转换后与 PNG 逐像素一致。
- 完整 MP4 已完成解码检查。
- 部分中间视线角度差异较小；这些是经过逐帧复核后保留的视觉警告，不是缺帧或方向错误。

## 安装包边界

包标识为 `yue-li`，与旧版 `zi-yue` 并存。安装器在写入前后校验清单和图集，并备份已有同名月璃。macOS 在独立临时目录验证安装、备份与损坏输入拒绝；Windows 脚本未在 Windows 设备实测。

图集的帧时长由客户端决定。交互预览中的慢放按钮仅用于观看，不会让已安装宠物改变播放速度。
