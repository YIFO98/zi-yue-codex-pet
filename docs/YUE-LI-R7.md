# 月璃 R7 · v3.0.1 · 2026-10-15

鼠标移到月璃身上时，原有悬停动作切换较忙。R7 将悬停集中为“准备 → 高举星星 → 保持并轻眨眼 → 继续保持 → 收回”，中间三帧保持同一姿势，共 420 毫秒。

## 行为与边界

- 单轮仍是客户端规定的 840 毫秒。本版减少动作切换，不提供实际播放倍速控制。
- 在本机核对的桌面客户端中，悬停默认连续播放三轮，然后回到慢速待机；实际表现随客户端版本而定。
- 预览新增三轮悬停模拟，待机帧时长与核对过的客户端保持一致。预览慢放仅用于观看。
- 相比 v3.0.0，仅悬停所在的第 4 行（从 0 开始计数）变化，其他十行逐像素相同。
- 角色只做小幅抬起；起始与结束落在同一基线，举星期间保持稳定。

## 验证

- 透明 v2 图集为 1536 × 2288，73 个有效帧，15 个空白格；本地及 Pets 预检通过。
- 当前宠物保存后回读像素与确认稿一致。
- 包内 WebP 无损转换后与确认的 PNG 逐像素一致。
- macOS 隔离目录完成首次安装、从 R4 升级、备份、校验和损坏包拒绝写入测试。
- Windows 脚本的清单与哈希已核对，尚未在 Windows 设备实测。
